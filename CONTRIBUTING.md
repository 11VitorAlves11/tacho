# Contributing to Tacho

Thank you for helping improve Tacho.

1. Open an issue for substantial product or schema changes.
2. Create a short-lived branch such as `feat/import-source` or `fix/image-auth`.
3. Use Conventional Commit messages.
4. Add focused tests and update public documentation.
5. Run the commands in `docs/development.md` before opening a pull request.
6. Open a pull request against `main` and explain data/configuration impact.

Pull requests must not include real recipes, photographs, credentials, domains,
host paths or other private infrastructure information. Database migrations must
be forward-safe and accompanied by upgrade/rollback notes.

By contributing, you agree that your contribution is licensed under AGPL-3.0.
