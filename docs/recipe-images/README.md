# Demonstration recipe images

These six original food images were generated with the built-in `imagegen` tool for the
README demonstration. They are illustrative images, not photographs of tested recipes.
The capture script uploads them as recipe covers before opening the pages for screenshots.
They are not seeded into normal installations.

## Prompts

Shared prompt for `rice.png`, `soup.png`, `pancakes.png`, `salad.png` and `vegetables.png`:

> Use case: photorealistic-natural. Landscape food photograph for a recipe app demo:
> {dish}, served in an off-white ceramic dish on a pale stone kitchen table. Natural
> window light, appetizing realistic homemade food, overhead three-quarter view, dish
> centered. No text, no logos.

| File | Dish |
|---|---|
| `rice.png` | vegetable rice with peas and diced carrots |
| `soup.png` | smooth orange pumpkin soup |
| `pancakes.png` | oat and banana pancakes |
| `salad.png` | chickpea salad with diced tomatoes and cucumber |
| `vegetables.png` | roasted potatoes and carrots with rosemary |
